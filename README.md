# Caffeination Burleigh: website concept

A homepage concept PeriscoPe put together for Caffeination Burleigh (14/76 Township Drive, Burleigh Heads) to start a conversation about a new website. It is not their live site and nothing here has been agreed.

- Served with GitHub Pages from the `main` branch root.
- `noindex` and `robots.txt` keep it out of search engines so it never competes with caffeination.com.au.
- Logo, menu and photos belong to Caffeination Burleigh and are used here only for this preview. Take the repo down or make it private if they ask.

Contact: Kurt Seres, PeriscoPe.
